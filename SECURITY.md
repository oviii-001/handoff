# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The HandOff team takes the security of agent permissions seriously. If you believe you have found a security vulnerability in any repository component:

1. Please do **NOT** report security vulnerabilities through public GitHub issues.
2. Instead, report them via email to `ismamhasanovi@gmail.com`.
3. Include detailed steps to reproduce the vulnerability.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to coordinate disclosure.
